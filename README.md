# Cybersecurity Home Lab

This project documents the creation of a penetration testing lab
using Kali Linux and Metasploitable in VirtualBox.

The lab is designed to practice:

- Network discovery
- Port scanning
- Vulnerability identification
- Exploitation using Metasploit
